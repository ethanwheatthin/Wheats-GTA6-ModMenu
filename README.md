# Wheats-GTA6-ModMenu

A free, non-commercial, **single-player-only** PC mod menu for GTA V
(Menyoo-style trainer, built clean-room), structured so the game layer can be
swapped for GTA VI once a PC version and tooling exist.

See [`AGENTS.md`](AGENTS.md) for the full project overview, stack, commands,
and hard rules (single-player only, no online features, no Rockstar assets,
clean-room only). See [`docs/setup.md`](docs/setup.md) for what's required to
start development, and [`docs/specs/menyoo-parity.md`](docs/specs/menyoo-parity.md)
for the feature checklist.
